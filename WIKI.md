# CHAOSS DEI Badging Project Wiki 📖

Welcome to the **CHAOSS DEI Badging Project Wiki**! This document serves as a centralized reference guide to help contributors, maintainers, and community members understand the purpose, architecture, features, and contribution workflows of the DEI Badging initiative.

---

## 1. About the Project

The **DEI (Diversity, Equity, and Inclusion) Project Badging Initiative** is an official project under the [CHAOSS Community](https://chaoss.community/) (Linux Foundation). It provides a structured, peer-reviewed badging process to recognize open-source software projects and events that actively demonstrate an ongoing commitment to diversity, equity, and inclusion.

By submitting their repositories or events for review, open-source communities reflect on their practices, implement actionable improvements, and signal to potential contributors that their spaces are safe, inclusive, and welcoming for all.

---

## 2. Core Objectives

- **Promote Community Health:** Foster open, inclusive, and psychologically safe environments across open-source ecosystems.
- **Provide Actionable Benchmarks:** Help project leaders and event organizers self-reflect using standardized, transparent CHAOSS DEI metrics.
- **Public Recognition:** Award digital verification badges that maintainers can proudly display on their project READMEs and event websites.
- **Continuous Improvement:** Offer structured feedback and inclusive language guidance at every badging tier to help communities level up their practices over time.

---

## 3. Core Features

- **Automated Repository Scanning:** The badging scanner bot inspects a project's repository for the presence and validity of a `DEI.md` file.
- **Tiered Badging Program:**
  - **Bronze Badge:** Awarded upon demonstrating the presence and alignment of a `DEI.md` file based on core CHAOSS metrics.
  - **Silver / Gold / Higher Badges (In Development):** Expanded tiers targeting deep metric conformance and continuous community assessment.
- **Event Badging Portal:** Comprehensive application and review system for virtual, hybrid, and in-person conferences seeking DEI verification.
- **Public Badged Directories:** Interactive, searchable directories listing all recognized open-source projects and badged community events.
- **GitHub / GitLab OAuth:** Seamless onboarding allowing maintainers to log in, select repositories, and trigger badging workflows in a few clicks.

---

## 6. Core Areas of Contribution

We welcome contributions across all skills and backgrounds:

1. **Frontend Development (React / SCSS / MUI):**
   - Enhance UI components, responsive layouts, search filters, and table pagination.
   - Improve web accessibility (WCAG 2.1 AA) and mobile navigation.
2. **Backend & Automation (Node.js / Express / GitHub Bots):**
   - Improve repository parsing, webhook handlers, and scanner bot logic.
   - API endpoints for badge issuance, status tracking, and event applications.
3. **Documentation & Technical Writing:**
   - Maintain the project Wiki, contributor guides, and DEI guidance docs.
   - Write clear tutorials for maintainers applying for badging.
4. **Design & UX:**
   - Craft badges, SVG icons, and wireframes for new application flows.
5. **Issue Triage & Peer Review:**
   - Review applicant `DEI.md` files and participate in event badging evaluations.
