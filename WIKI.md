# DEI Project Badging - Project Wiki

## About the Project
The DEI (Diversity, Equity, and Inclusion) Project Badging Initiative is a CHAOSS (Community Health Analytics Open Source Software) project that recognizes and rewards open-source projects demonstrating commitment to diversity and inclusion. This initiative helps projects showcase their dedication to creating an inclusive environment while providing a framework for continuous improvement in DEI practices.

## Core Objectives
1. **Promote Inclusivity**: Encourage open-source projects to adopt and maintain inclusive practices.
2. **Recognition**: Provide visible recognition to projects that meet DEI standards.
3. **Continuous Improvement**: Offer a pathway for projects to assess and enhance their DEI efforts.
4. **Community Building**: Foster a more diverse and welcoming open-source ecosystem.
5. **Standardization**: Establish common standards for DEI practices in open-source projects.

## Core Features
- **Automated Badging System**: Automated scanning of project repositories for DEI compliance.
- **Tiered Badging Levels**: Multiple badge levels to recognize different stages of DEI maturity (currently Bronze level available).
- **DEI.md Validation**: Automated checking of DEI.md files for required metrics and best practices.
- **Inclusive Language Analysis**: Provides feedback on language usage to promote inclusivity.
- **Badge Display**: Easy-to-embed badge images for project documentation.
